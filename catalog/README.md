# Каталог модулей eBackup

Готовые **декларативные модули** (`*.module.json`) для популярных программ и игр.
Приложение видит этот каталог и умеет поставить нужный модуль в один клик
(раздел «Модули → Каталог», доступен с версии 1.1).

## Что внутри
- [`index.json`](index.json) — список модулей с описаниями (его читает приложение);
- [`modules/`](modules) — сами файлы модулей.

## Как устроен модуль
Декларативный модуль — это **только данные**: какие папки и файлы бэкапить. Кода в нём
нет, поэтому он безопасен к установке. Разрешены только пользовательские данные
приложений — корни `{APPDATA}`, `{LOCALAPPDATA}`, `{PROGRAMDATA}` (никаких ключей,
профилей или Program Files). Пример:

```json
{
  "id": "minecraft-java",
  "displayName": "Minecraft (Java Edition)",
  "minApiVersion": "1.0",
  "entries": [
    {
      "tokenPath": "{APPDATA}/.minecraft",
      "type": "Directory",
      "archivePath": "minecraft",
      "excludeGlobs": ["assets/**", "versions/**", "logs/**"]
    }
  ]
}
```

Поля записи:
- `tokenPath` — что бэкапить; начинается с разрешённого корня (`{APPDATA}` и т.п.);
- `type` — `Directory` или `File`;
- `archivePath` — куда положить внутри архива;
- `excludeGlobs` — маски-исключения (кэши, логи и прочее, что не нужно).

## Как добавить свой модуль
1. Форкни репозиторий.
2. Положи `modules/<твой-модуль>.module.json` (формат выше; `id` — латиница, цифры и `._-`).
3. Добавь запись о нём в [`index.json`](index.json): `id`, `name`, `description`,
   `category`, `author`, `version`, `file`, `tokens`.
4. Открой Pull Request. После проверки и одобрения модуль появится в каталоге — и его
   увидят все пользователи eBackup.
