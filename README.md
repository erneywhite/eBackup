# eBackup

> 🌐 **Languages:** **Русский** (этот файл) · [English](README.en.md)

**eBackup** — модульное приложение для Windows, которое делает бэкапы важных
данных и настроек приложений, хранит их сразу в нескольких местах (локально,
сетевой диск, FTP/SFTP, облако) и умеет аккуратно раскладывать всё обратно по
местам — даже на другом компьютере или после переустановки ОС.

Первый модуль — **полный бэкап OBS Studio** (сцены, профили, настройки,
подключения).

> ⚠️ Проект в ранней разработке (v1, вертикальный срез). API и форматы могут меняться.

## Зачем
Когда переезжаешь на новый ПК или переустанавливаешь систему, легко потерять
настройки приложений, которые копились годами. eBackup собирает их в один
переносимый архив `.ebk` с **манифестом путей**, поэтому при восстановлении
файлы ложатся ровно туда, куда нужно, даже если изменились имя пользователя,
буква диска или путь установки.

## Возможности
**Готово в v1 (вертикальный срез):**
- 📦 Формат архива `.ebk` (ZIP + `manifest.json` с токенизированными путями)
- 🧩 Модульная система: декларативный дескриптор + опциональный код-хук
- 🎬 Модуль **OBS Studio** (`%APPDATA%\obs-studio`)
- 💾 Хранилище: локальная / сетевая папка
- ♻️ Восстановление по манифесту с политикой разрешения конфликтов
- 🖥️ CLI для запуска и отладки

**В планах:**
- 🔐 Опциональное шифрование архива (AES-256-GCM, ключ из парольной фразы)
- 🌐 Хранилища: SFTP, FTP, Google Drive и др. — несколько одновременно
- 🪟 GUI на WinUI 3, иконка в трее
- ⏰ Расписание через Планировщик Windows, версионирование и retention
- 🗂️ Бэкап ключей реестра, новые модули приложений

## Архитектура

| Проект | Назначение |
|---|---|
| `eBackup.Core` | Ядро: модель манифеста, движок бэкапа/восстановления, формат архива, абстракции `IStorageProvider` и `IBackupModule` |
| `eBackup.Storage.Local` | Хранилище в локальной/сетевой папке |

| `eBackup.Cli` | Консольный интерфейс |
| `eBackup.Tests` | Тесты |
| `eBackup.App` *(позже)* | GUI на WinUI 3 |

Подробнее — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).

## Сборка и запуск

Требуется [.NET SDK 9.0+](https://dotnet.microsoft.com/download).

```powershell
dotnet build eBackup.sln
dotnet test  eBackup.sln
```

CLI:

```powershell
# список доступных модулей
dotnet run --project src/eBackup.Cli -- list-modules

# создать бэкап всех модулей в папку .\backups
dotnet run --project src/eBackup.Cli -- backup --out .\backups

# восстановить из архива
dotnet run --project src/eBackup.Cli -- restore --archive .\backups\ebackup-20260609-120000.ebk
```
