**eBackup** бэкапит настройки приложений и любые твои папки, складывает архивы сразу
в несколько мест — от локальной папки и NAS до Google Drive, Dropbox и MEGA — и аккуратно
раскладывает всё обратно, даже на другом компьютере или после переустановки системы.
Тёмный фирменный интерфейс, фоновая служба и полноценный CLI.

Бесплатно, с открытым кодом, без подписок и пейволлов. Если eBackup пригодился —
можешь [угостить автора кофе ☕](https://dalink.to/toristarm).

## Почему eBackup

- 🗄️ **8 типов хранилищ сразу** — локальная папка, NAS, SFTP, FTP/FTPS, S3, WebDAV, Google Drive, Dropbox, MEGA. Один бэкап — несколько мест.
- 🛡️ **Фоновая служба** — бэкапы и расписания работают, даже когда в систему никто не вошёл, и без открытого окна.
- 🔐 **Шифрование AES-256-GCM** — архивы безопасно класть хоть на чужой сервер.
- ✅ **Проверка каждого бэкапа** — архив перечитывается и сверяется по SHA-256; битые данные не доедут ни до одного хранилища.
- 🧩 **Модули и каталог** — OBS, VTube Studio, браузеры, игры и не только; ставятся в один клик.
- 📦 **Переносимый формат `.ebk`** — пути в архиве токенизированы, восстановление работает на любом ПК.

## Установка

Скачай установщик со страницы [**Releases**](https://github.com/erneywhite/eBackup/releases/latest)
(`eBackup-setup-x.y.z-x64.exe`) и запусти. Приложение **self-contained** — .NET ставить
не нужно. После установки eBackup сам проверяет обновления и умеет обновляться одной кнопкой.

Вместе с приложением ставится фоновая служба **eBackup** (LocalSystem, автозапуск) — благодаря
ей бэкапы и расписания работают без открытого окна и даже без входа в систему. Удаление
приложения убирает и службу.

> Windows 10/11 (x64). Установка в Program Files требует прав администратора.

## Хранилища

Сколько угодно одновременно, у каждого — кнопка «Тест», авто-проверка доступности ✓/✕
и счётчик занятого места на «Обзоре».

| Тип | Детали |
|---|---|
| 📁 Папка / сетевой диск | UNC-пути `\\nas\share`, опциональная SMB-авторизация (временное подключение) |
| 🔑 SFTP | пароль или приватный ключ **содержимым**; выбор удалённой папки **деревом** |
| 📡 FTP / FTPS | FluentFTP; самоподписанные сертификаты NAS допускаются явным флагом |
| 🪣 S3-совместимые | AWS S3, MinIO, Backblaze B2, Cloudflare R2…; path-style, префиксы-«папки» |
| ☁️ WebDAV | Nextcloud, ownCloud, Яндекс.Диск и др. (пароли приложений) |
| 🟢 Google Drive | OAuth через браузер; scope `drive.file` — приложение видит **только свои** файлы |
| 🔵 Dropbox | OAuth; изолированная папка приложения |
| 🔴 MEGA | вход один раз (логин + пароль + код 2FA), дальше — по сохранённой сессии, в т.ч. по расписанию |

## Что умеет

**Бэкап.** Модули и любые свои папки, несколько целей за один прогон, опциональное шифрование,
имя компьютера в имени архива, выбор степени сжатия. Перед стартом проверяется свободное место —
понятный отказ вместо обрыва на середине. А прогресс показывает «жидкий» индикатор-вода с честной
физикой 🌊

**Проверка.** После каждого бэкапа архив перечитывается целиком (распаковка сверяет CRC32),
файлы сличаются по SHA-256 с манифестом, на каждой цели контролируется размер. Битые данные
не доедут до хранилища.

**Расписания.** Ежедневно / по дням недели / каждые N часов / **раз в день при простое ПК**.
У каждого расписания свой набор модулей, папок, целей и шифрования; есть «Выполнить сейчас».
Выполняет их фоновая служба — срабатывают, **даже когда в систему никто не вошёл**, окно держать
открытым не нужно. Зашифрованные расписания тоже идут сами (фразу служба хранит под машинным ключом).

**Восстановление.** В исходные места или в любую папку; режимы конфликтов (заменить с `.bak` /
перезаписать / только недостающие). Внешние ассеты сцен OBS раскладываются куда укажешь, а пути
в сценах переписываются автоматически.

**Архивы и браузер.** Списки по всем хранилищам (размер, дата, 🔒 у зашифрованных). «Открыть» —
дерево содержимого с галочками: восстановить выбранные файлы или просто скачать их в папку.
Удалённые архивы читаются **кусками** (SFTP seek / HTTP Range): оглавление 100-гигового облачного
архива открывается за секунды, а качаются только выбранные файлы.

**История.** Журнал всех операций (бэкапы ручные и по расписанию, восстановления, извлечения).
У каждого запуска — полный лог с таймкодами до миллисекунд: каждый файл с размером, скорость
заливки по целям, верификация, ошибки. Прерванные запуски честно помечаются.

**По мелочи.** Уведомления о результате (✅/❌), трей и автозапуск с Windows, retention
«хранить последних N» на всех целях, очистка временных файлов, быстрые кнопки к конфигам и логам.

## Безопасность

- 🔐 **Шифрование архива** — AES-256-GCM по чанкам, ключ из парольной фразы через **Argon2id**.
- 🔑 **Секреты подключений** (пароли, ключи, OAuth-токены, сессия MEGA) хранятся зашифрованными
  и намеренно **не переносятся** на другой ПК: у службы — под машинным ключом, у CLI — через Windows DPAPI.
- 🚫 **Fail-closed** — парольная фраза идёт разовым тикетом, не попадает в логи и историю; нет фразы — нет архива.
- 🛡️ Архивы проверяются от path-traversal, а каждый бэкап верифицируется до отправки.

**Формат `.ebk`** — это ZIP + `manifest.json` с токенизированными путями (`{APPDATA}` и т.п.),
поэтому архив переносим между компьютерами. Имена говорящие и сортируемые:
`ebackup_MY-PC_obs_2026-06-19_19-40-01.ebk`.

## Модули

Модуль описывает, *что* бэкапить у конкретной программы — без ручного выбора десятков папок.

- 🎬 **Встроенные** (со «умным» поиском установки): **OBS Studio** (конфиг без кэшей, плагины
  и зависимые ассеты сцен) и **VTube Studio** (модели, предметы, фоны и конфиги; игру находит
  в любой Steam-библиотеке, тяжёлые трекеры не тащит).
- 🧩 **Каталог** — «Модули → Каталог» внутри приложения: SSH, VS Code, Minecraft, Vintage Story,
  Firefox, Waterfox… Установка в один клик, список живёт в этом репозитории.
- 📝 **Свои декларативные модули** — положи `*.module.json` в `%APPDATA%\eBackup\modules`
  (или `ebackup module-add файл`), и приложение начнёт бэкапить описанные пути. Без кода и пересборки:

```json
{
  "id": "myapp",
  "displayName": "My App",
  "entries": [
    { "tokenPath": "{APPDATA}/MyApp", "type": "Directory",
      "archivePath": "config", "excludeGlobs": ["**/Cache/**"] }
  ]
}
```

Хочешь поделиться модулем с другими — добавь его в [каталог](catalog/) через pull request.

## CLI

Всё скриптуемо: `backup`, `restore`, `storage-list` / `storage-test` / `storage-ls`, `module-add`.
Парольная фраза для автоматизации — через переменную окружения `EBACKUP_PASSPHRASE`.

## Для разработчиков

Нужен [.NET SDK 9.0+](https://dotnet.microsoft.com/download) (Windows 10/11).

```powershell
dotnet build eBackup.sln
dotnet test  eBackup.sln
```

| Проект | Назначение |
|---|---|
| `eBackup.Abstractions` | Контракт плагинов (интерфейсы, модель манифеста) — стабильная граница |
| `eBackup.Core` | Движок бэкапа/восстановления с верификацией, шифрование, реестр модулей, расписания, история |
| `eBackup.Security` | Защита секретов: Windows DPAPI (CLI) и машинный ключ службы |
| `eBackup.Storage` (+ `.Sftp`, `.Local`) | Единая модель хранилищ, OAuth (PKCE + loopback), чтение удалённых архивов кусками |
| `eBackup.Modules.Obs`, `eBackup.Modules.VTubeStudio` | Встроенные модули со «умным» поиском |
| `eBackup.Ipc` | Контракт и транспорт named-pipe между GUI и службой |
| `eBackup.Service` | Фоновая служба LocalSystem: вся привилегированная работа |
| `eBackup.App` | GUI на WinUI 3 — тонкий клиент службы |
| `eBackup.Cli` | Консольный интерфейс |

Подробнее об устройстве — в [docs/ARCHITECTURE.md](docs/ARCHITECTURE.md).
